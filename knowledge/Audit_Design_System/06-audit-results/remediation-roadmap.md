## Ordre de traitement

1. Corriger à la source : un défaut de token ou de contrat partagé passe avant ses symptômes dans les composants.
2. Traiter tous les P0, puis les P1.
3. Regrouper ensuite les corrections par cause commune.
4. Réévaluer les composants touchés après chaque lot.
