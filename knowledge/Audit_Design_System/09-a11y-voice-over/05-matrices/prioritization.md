# Test Prioritization

## Priority 1 — High impact and high reuse

Button, Link, Text Input, Checkbox, Radio Group, Select, Dialog (modal), Error Message, Tabs, Combobox.

## Priority 2 — Navigation and dynamic feedback

Navigation Menu, Accordion, Search Field, Notification, Alert, Date Picker, Pagination, Autocomplete.

## Priority 3 — Remaining components

All other components, prioritized by usage frequency, complexity, release exposure, and severity of prior defects.

Reprioritize after changes to shared primitives, focus logic, or accessibility APIs.
