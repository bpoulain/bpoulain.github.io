# Shared Accessibility Rules

1. Every interactive control has an appropriate accessible name and role.
2. Exposed states and values reflect the current UI.
3. Navigation and focus order preserve meaning and task completion.
4. All supported interactions are operable through the relevant input method.
5. Dynamic updates and errors are discoverable without disruptive repetition.
6. Decorative content is not needlessly announced; meaningful content remains available.
7. Visible labels, accessible names, and instructions are consistent.
8. A single VoiceOver observation is evidence, not proof of universal accessibility.
