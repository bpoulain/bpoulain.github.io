# Test Environments

Record for every campaign: date, device model, macOS/iOS build, Safari version, VoiceOver language/verbosity, keyboard layout, browser zoom, component version, and URL/build identifier.

| Environment | Baseline |
|---|---|
| macOS | Safari + VoiceOver, physical keyboard |
| iOS | Safari + VoiceOver, touch exploration and swipe navigation |
| Optional | iOS external keyboard; native application implementation |

Use stable test data. Disable unrelated notifications where possible. Retest on supported OS versions and device classes. Do not assume that a desktop Safari result predicts an iOS Safari result.
