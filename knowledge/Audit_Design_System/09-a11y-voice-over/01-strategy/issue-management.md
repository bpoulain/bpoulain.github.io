# Accessibility Issue Management

## Severity

| Level | Definition | Example |
|---|---|---|
| Blocker | Core task impossible | Modal cannot be dismissed |
| Major | Significant barrier or misleading state | Error is not discoverable |
| Minor | Workaround exists but causes friction | Redundant announcement |
| Improvement | Non-normative usability enhancement | More concise help text |

## Lifecycle

Open → Triaged → In progress → Ready to retest → Verified → Closed. Reopen if regression reproduces.

Each issue includes component/version, platform/build, test ID, expected and actual results, steps, impact, likely cause (if known), and evidence. Separate confirmed normative failures from usability recommendations.
