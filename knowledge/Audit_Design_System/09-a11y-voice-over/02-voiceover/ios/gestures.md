# VoiceOver Gestures — iOS

| Task | Common gesture |
|---|---|
| Next/previous accessible item | One-finger swipe right/left |
| Activate focused item | One-finger double tap |
| Explore screen | Drag one finger over the screen |
| Scroll | Three-finger swipe |
| Change rotor setting | Two-finger rotation gesture |

Gestures can be customized. Verify actual behavior on the device and document alternate gestures when relevant.
