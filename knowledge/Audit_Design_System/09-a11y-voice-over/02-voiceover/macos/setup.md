# VoiceOver Setup — macOS

1. Open **System Settings → Accessibility → VoiceOver** and enable VoiceOver, or use **Command-F5** when supported by the keyboard/system settings.
2. Open VoiceOver Utility to note verbosity and navigation preferences.
3. Use Safari, open the target page, and confirm the keyboard focus is in the page.
4. The VoiceOver modifier (`VO`) is usually Control-Option; settings may differ.
5. Keep Safari and macOS versions in the test record.

Use headphones if needed and record spoken output without treating punctuation or word order as a strict assertion.
