# VoiceOver Commands — macOS

| Task | Common command |
|---|---|
| Move to next/previous item | `VO + Right/Left Arrow` |
| Interact with a group | `VO + Shift + Down Arrow` |
| Stop interacting with a group | `VO + Shift + Up Arrow` |
| Activate current item | `VO + Space` |
| Open VoiceOver rotor | `VO + U` |

Commands can vary with settings, keyboard, and VoiceOver version. Confirm using VoiceOver Help (`VO + H`) when needed. Use native keyboard controls for separate keyboard testing.
