# Keyboard Navigation — macOS

Test **without VoiceOver** first: Tab and Shift-Tab should reach keyboard-focusable controls in a logical order; Space/Return behavior depends on the native control pattern. Verify a visible focus indicator and no keyboard trap.

With VoiceOver, use `VO + Right Arrow` and `VO + Left Arrow` to move through accessible items. `VO + Space` commonly activates the current item. Browser and VoiceOver navigation are not identical to Tab order; test both. On some keyboards, `VO` means Control-Option.
